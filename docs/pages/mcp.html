This site has an MCP server that lets you search the blog from any MCP-compatible AI client.

Endpoint: https://tantaman.com/api/mcp

Claude Desktop

Add this to your claude_desktop_config.json:

{
  "mcpServers": {
    "tantaman-blog": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://tantaman.com/api/mcp"
      ]
    }
  }
}

Claude.ai

Go to Settings > Integrations > Add remote MCP server and enter the endpoint URL above.

Other Clients

Any MCP-compatible client can connect using the endpoint URL. The server exposes a search_blog tool that returns relevant passages from blog posts.
